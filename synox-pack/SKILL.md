# 日記（diary）

一篇日記＝**某一天**＋**一個題組**（一組問題）的答案。同一天可以有好幾篇，一個題組一篇；同一天同一個題組再寫一次＝更新那一篇。
每個工具只讀最後一行 JSON 信封：`{"ok": true, "result": {…}}`，失敗 `{"ok": false, "error": "一句人話"}`——錯誤那一句直接轉述給使用者就好。

## 工具一覽

| 工具 | 做什麼 | 什麼時候用 |
|---|---|---|
| `diary__templates` | 全部題組：名稱、`when`（什麼時候用）、`minutes`、`moods`、`tags`、分類（`structure`／`reflection`／`flow`） | 要挑題組、使用者問有哪些格式 |
| `diary__template` | 一個題組的每一題：`id`、`kind`（題型）、`options`、`blanks`、`ai_hint`（這一題怎麼填） | 填之前一定先看 |
| `diary__suggest` | 替一段文字排出最像的幾個題組，每一個都附 `why`（看到哪個字→哪個步驟） | 使用者說「你幫我挑」。把 `why` 用一句話講給他、讓他選，不要自己決定 |
| `diary__categories` | 分類字彙表：每一種結構、反思層級、步驟、標籤各有哪些題組 | 使用者想「照分類挑」（先問要不要信仰的、要幾段的） |
| `diary__show` | 某一天的每一篇：`text`（純文字）、`answers`、`provenance`（哪幾題是 AI 整理的） | 使用者要看某天；整理之前先看那天寫了什麼 |
| `diary__list` | 最近寫過的日記：日期、題組、字數、編號 | 「我最近寫了哪幾天」 |
| `diary__put` | 把**作者自己的話**寫進某一天、某個題組，**只填空著的題目**（已經有寫的回在 `kept`） | 使用者交代了要填什麼 |
| `diary__put_ai` | 把**你整理過的版本**寫進去：每一題標「AI 整理」、附作者原文；作者已經寫過的題目不動（`protected`） | 使用者說「幫我潤飾」「幫我整理成日記」 |
| `diary__overwrite` | 換掉**點名的**幾題（`fields`＝題目 id，逗號分開）。會送確認卡 | 使用者要改某一兩題（補經文原文、改錯字） |
| `diary__export` | 做成一頁 HTML ＋ 一張卡片 SVG，回完整路徑 | 「做成圖」「給我一頁」；改完內容再叫一次就是新的 |
| `diary__settings`／`diary__settings_set` | 看、改設定（預設題組、版型、幾點換日 `day_start_hour`、匯出資料夾…） | 使用者說「以後都用三行日記」「我都半夜寫，兩點以前算前一天」 |

`date` 收 `YYYY-MM-DD`、`today`、`yesterday`（照設定 `day_start_hour` 換日）；「上週五」自己換成日期。

## 情境

**「幫我記一下／幫我整理成日記」（使用者把話打出來了）**

1. `diary__suggest`（`text`＝他的話）→ 把前兩三個題組跟 `why` 用一句話講給他、讓他選；他指定了就用指定的。對不上名稱就 `diary__templates` 找兩三個最像的給他選，不要猜。
2. `diary__template`（看每一題的 `kind`、`options`、`blanks`、`ai_hint`）。
3. 要**原文照存**：`diary__put`，answers 用他的字。要**潤飾**：`diary__put_ai`，JSON 一定要有 `source_text`（他的原話，一字不改）；每一題各自對應的原文放 `sources`。
4. `diary__export`（同一個 `date`、`template`）→ 把回來的檔案給他。
5. 回覆只說做好了哪一篇、填了幾題、哪幾題標了 AI 整理；**不要把日記整段貼回去**。

**「把某一題改一下」（例：經文只寫了出處，要補原文）**

1. `diary__show` 看那一篇現在的 `answers`（找出題目 id）。
2. `diary__overwrite`：`fields`＝那一兩題的 id、`author`＝`user`（他說的話）或 `ai`（你整理的，JSON 附 `source_text`）。**不要用 `all`**，除非他明說整篇重寫。
3. `diary__export` 重新產出。

**「我某天寫了什麼」**：`diary__show`。輸出只有你看得到——他要全文就給全文，要重點就整理重點；只給他問的那一天。

**「有哪些格式／幫我分類」**：`diary__categories` → 先問他要哪一種（不談信仰的／有禱告的；一段式／三段式），再列那一類的題組。

## 填寫的原則（每一題的 `ai_hint` 是細節）

- **用作者自己的話。** 可以整理、拿掉贅字，不要改寫成你的句子，**不要加作者沒寫的情節、感受、結論**。
- **AI 整理的版本一定走 `diary__put_ai`**，不要用 `diary__put` 假裝是作者寫的；`source_text` 永遠是他的原話。
- **不替作者下結論、不替作者認罪、不替作者打分數。** 「學到什麼」「主在哪裡」這種題目，作者沒說就留空。
- **沒提到的就留空。** 空的題目輸出時不會出現，不是失敗。勾選題只能用那一題的選項、只照他自己說的選。
- **經文只照抄作者寫過的**，不要憑記憶補經文原文；只給出處。
- 信仰類題組（`reflection` 是 `devotional`／`prayer`）只在他提到信仰、或他自己選的時候用。
- 回傳的 `ignored`＝對不上的題目（不是這個題組的、不是選項）；`protected`＝作者寫過、沒動的題目——要換要用 `diary__overwrite` 並先問他。

## 隱私

日記是最私人的東西：工具的輸出不要整段複述、不要記到別的地方；回結果就好（哪一篇、幾題、檔案在哪）。
